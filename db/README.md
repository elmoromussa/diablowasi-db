# Base de dades

Carpeta reservada per a la base de dades Access tancada per a l'anàlisi (v25g). La còpia pública s'hi afegirà amb els quatre camps de coordenades de `T_STRUCTURES` buidats (`Coord_Lat_WGS84`, `Coord_Lon_WGS84`, `Coord_E_UTM`, `Coord_N_UTM`); l'altitud, la precisió i l'azimut de façana es conserven. La base completa és disponible a petició a l'autor per a finalitats de recerca.

Mentrestant, la base es pot reconstruir buida amb el codi de l'etiqueta `v25g` seguint el `README.md` de l'arrel.
